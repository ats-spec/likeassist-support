PROFILE SHARING

自分の設定を、保存・共有。

共有するのは検索設定だけ。読み込む前に内容を確認できます。

1. アプリから保存

  1. 「設定 → サイト・検索設定」で共有したいサイトを選択します。
  2. 「書き出す」を押し、共有内容の注意を確認します。
  3. 端末の「ファイルに保存」などを選び、JSONファイルを保存します。

サイト名、対象ドメイン、開始URLのパス、検索ボタン名・検索文字・ON/OFFが含まれます。自動入力の個人情報、テンプレート、閲覧履歴、購入情報は含みません。ただし検索文字やURL自体に秘密の情報が含まれていないか確認してください。

2. 自分のGitHubで共有

  1. ご自身のGitHubの公開リポジトリを開きます。
  2. 「Add file → Upload files」で保存したJSONを選び、変更を保存します。
  3. 公開したファイルのページURLをコピーして共有します。

GitHubアカウントへのログイン・ファイル投稿はGitHubで行います。アプリから直接投稿はしません。公開した情報は誰でも閲覧できるため、公開先の管理と削除はご自身で行ってください。

3. 確認して読み込む

  1. アプリの「設定 → サイト・検索設定 → プロファイルを共有・読み込み」を開きます。
  2. 「保存したJSONファイルを読み込む」、またはGitHub URLを貼り付けて「URLから読み込む」を選びます。
  3. サイト名・ドメイン・開始URL・検索文字を確認して保存します。同じドメインの設定がある場合は置き換わります。

対応するURLはGitHubのファイルページ、raw.githubusercontent.com、GitHub Pagesです。ファイルは64KB以下・形式バージョン1。読み込んでもサイトを自動で開いたり、クリックしたりはしません。

練習用プロファイル

使い方ページ用のJSONを保存

アプリのURL読み込み欄には、次のURLをコピーしてください。

https://ats-spec.github.io/likeassist-support/guide-profile.json

無料・Proの上限

無料は3サイト・各1検索ボタン、Proは20サイト・各5検索ボタンです。読み込みも同じ上限が適用されます。上限を超えるファイルは、内容を減らすかプランを変更してから再度読み込んでください。

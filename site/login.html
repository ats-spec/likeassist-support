PROFILE GUIDE

選ぶのは、プロファイルだけ。

通常は、使いたいサイトのプロファイルを1つ作れば利用できます。同じサイトでログイン環境を分けたい場合に限り、プロファイルを追加します。以下はその場合の例です。「私用」「仕事用」などの名前は自由で、特定の名前やGoogle専用の設定は必要ありません。

1プロファイル＝1つのログイン環境

例：Googleを1つの環境で使う

プロファイル名は自由に設定

この環境用の検索・自動入力設定

このプロファイルのタブ同士はログインを共有

追加する例：同じGoogleでログインを分ける

必要な人だけ、もう1つプロファイルを作成

「私用」「仕事用」など名前も自由

1つ目のプロファイルとはログインを分離

アプリ名義は目印です。Googleなどのサイト内で利用者を変更することまでは制限しません。送信前にはサイト内の利用者も確認してください。

作成と切替

  1. 1つのログイン環境だけでよい場合は、プロファイルを追加する必要はありません。
  2. 同じサイトでログイン環境を分けたい場合だけ、「☰ → 設定 → サイト・検索」から「サイト設定を追加」を開きます。
  3. 分けたいサイトと同じURLを登録し、見分けやすい名前を自由につけます。例の名前を使う必要はありません。
  4. 「☰ → プロファイルを開く」で使う名前を1つ選びます。その中でさらにアカウントを選ぶ必要はありません。
  5. 新しいプロファイルを開いたら、初回はそのプロファイルで使うアカウントをWebサイトでログインします。LikeAssistがログインボタンを自動で押したり、フォームを自動送信したりはしません。

入力途中の切替では確認が出ます。キャンセルすれば現在のページに留まります。

旧設定はどうなる？

以前の複数アカウントは、専用の保存先IDを維持して独立したプロファイルに分けます。タブ・お気に入り・履歴の対応も移します。元の通常ブラウザ用設定は残り、ログインを共有します。

旧設定に保存したID・パスワードは、元のプロファイルに残します。分割先へ自動コピーしません。プロファイル数が上限を超えても削除せず、設定から「利用枠の先頭へ移動」して使用対象を選べます。

既存の共有プロファイルを分離する場合は、設定内の「ログイン・パスワード → ログインを分離して使う」を選びます。通常ブラウザのログインはコピーせず、入力中のタブは閉じます。確認後に実行し、サイトでログインし直してください。

保存したアカウントをログイン欄に入力する

ID・メールアドレス欄またはパスワード欄をタップすると、使用中のプロファイルに保存したアカウントを選べます。選択 → Face ID、Touch IDまたは端末パスコードで本人確認 → 空欄に入力、の順です。内容を確認し、サイトのログインボタンはご自身で押してください。Appleの「パスワード」の候補とは別の機能です。

  1. 操作メニューの「このサイトの保存ID・パスワード」を開き、本人確認します。
  2. 「編集する」から、アカウント名・ID・パスワードを登録し、保存します。
  3. 通常はプロファイルのドメインを入力先に使います。Googleの google.com／www.google.com は accounts.google.com にも対応します。
  4. ほかのログイン先を使う場合だけ、保存情報にそのホスト名を指定します。共通設定では保存情報ごとの指定が必要です。
  5. Webページへ戻り、ログイン欄をタップして、使うアカウントを選びます。

以前から保存してある情報は、一度「このサイトの保存ID・パスワード」を本人確認して開くと候補表示の準備ができます。共通設定ではログイン先を追加して保存してください。候補のアカウント名とログイン先は本人確認前にも表示・判定に使います。IDとパスワードは本人確認後に取り出します。

入力済みの値は上書きしません。IDが別のアカウントになっているときは、IDを消してから選び直してください。IDとパスワードが別ページの場合は、それぞれの欄で同じアカウントを選びます。特殊な入力欄や埋め込み画面は対応しない場合があるため、コピー・貼り付けも利用できます。

閲覧・編集にも端末認証が必要です。アプリを離れるとロックし、未保存の編集は破棄します。基本自動入力は共通情報またはプロファイル専用を選べます。プロファイル複製や共有にはログイン情報・パスワード・個別自動入力を含めません。

無料とPro

無料は3プロファイル、Proは20プロファイル。同じサイトでログイン環境を2つに分ける場合は、プロファイル枠を2件使います。動作中のタブは無料3つ・Pro5つ。お気に入り・最近閉じたタブから必要なページを開き直せます。復元するのはURLと使用プロファイルで、入力内容は復元しません。

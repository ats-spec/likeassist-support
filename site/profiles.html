PROFILE SETTINGS

使いたいサイト設定へ、メニューからすばやく切り替え。

よく使うサイト設定に名前や色を付けておくと、操作メニューの「プロファイルを開く」から選べます。開始URLや検索ボタンも設定ごとに管理できるため、使うサイトに合わせて切り替えやすくなります。プロファイルは必須ではなく、必要なければ1つの設定のまま使えます。

使うサイト設定を、メニューから選び直す

たとえば、仕事用と買い物用など、使うサイト設定を分けて登録しておけば、「☰ → プロファイルを開く」から目的の設定を選べます。設定に付けた名前と色が目印になり、開始URLや検索ボタンも選んだ設定に合わせて使えます。仕事用・買い物用はあくまで例です。設定を分ける必要がなければ、1つのままで使えます。

機種変更や別の端末でも同じ検索設定を使いたい場合は、JSONファイルに書き出して読み込みます。自動同期ではなく、共有する内容を確認してから手動で移します。

共有されるのはサイト名・色・対象ドメイン・開始URL・検索ボタンの設定です。ログイン情報、自動入力の登録値、テンプレート、閲覧履歴は含まれません。

1. アプリから保存

  1. 「設定 → サイト・検索設定」で共有したいサイトを選択します。
  2. 「書き出す」を押し、共有内容の注意を確認します。
  3. 端末の共有画面で「ファイルに保存」などを選び、JSONファイルを保存します。

書き出しには、サイト名、表示色、対象ドメイン、開始URL（クエリとフラグメントを除く）、検索ボタンの表示名・検索文字・有効状態が含まれます。自動入力の登録値、テンプレート、ログイン情報、閲覧履歴、購入情報は含みません。ただし、サイト名、URLのパス、検索文字に個人情報や秘密の文字が含まれていないか、書き出し前に確認してください。

2. 自分のGitHubで共有

  1. ご自身のGitHubの公開リポジトリを開きます。
  2. 「Add file → Upload files」で保存したJSONを選び、変更を保存します。
  3. 公開したファイルのページURLをコピーして共有します。

GitHubアカウントへのログイン・ファイル投稿はGitHubで行います。アプリから直接投稿はしません。公開した情報は誰でも閲覧できるため、公開先の管理と削除はご自身で行ってください。

3. 内容を確認して読み込む

  1. アプリの「設定 → サイト・検索設定 → サイト設定を共有・読み込み」を開きます。
  2. 「保存したJSONファイルを読み込む」、またはGitHub URLを貼り付けて「URLから読み込む」を選びます。
  3. サイト名・対象ドメイン・開始URL・検索ボタンの内容を確認して保存します。

同じ対象ドメインのプロファイルが1件だけある場合は、そのプロファイルのサイト名・色・開始URL・検索ボタンを共有ファイルの内容で置き換えます。そのプロファイルに保存したログイン情報、自動入力、最後に開いたURLは残します。同じドメインのプロファイルが複数ある場合は自動で置き換えず、対象を選んで手動で反映します。

対応するURLはGitHubのファイルページ、raw.githubusercontent.com、GitHub Pagesです。ファイルは64KB以下、対応形式はバージョン1です。読み込んだだけでサイトを開いたり、ボタンを押したり、ログインしたりはしません。

練習用サイト設定

使い方ページ用のJSONを保存

アプリのURL読み込み欄には、次のURLをコピーしてください。

https://ats-spec.github.io/likeassist-support/guide-profile.json

無料・Proの上限

無料は3プロファイル・各1検索ボタン、Proは20プロファイル・各5検索ボタンです。読み込み先の上限も同じです。上限に達している場合は読み込めず、既存のプロファイル数や共有ファイル内の検索ボタン数を調整するか、Proをご検討ください。

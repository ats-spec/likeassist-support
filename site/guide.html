いつものWebを、使いやすく。

このページで検索と入力を練習できます。アプリの登録・ログインは不要です。

1. ページ内を検索

アプリ下部の「位置を検索」を押してみてください。初期設定の検索文字「お問い合わせ」を含むボタンへ移動します。候補が複数あるときは、同じボタンを押すたびに次の候補へ移動します。最初の候補へ移動した時点で1検索と数え、残りの候補を順に見る間は追加で数えません。途中でやめても、その1回は記録されます。候補が0件の場合は数えません。ボタンを勝手に押したり、フォームを送信したりはしません。

検索文字は「☰ → 設定 → サイト・検索設定」で変更できます。

お問い合わせの練習へ

タブとウィンドウを使い分ける

URL欄の下にある「＋」で現在のウィンドウにタブを追加し、タブ名で切り替え、右端の「×」で閉じます。最後の1枚は閉じられません。ページ内のリンクを長押しすると、現在のタブで開く、新しいウィンドウで開く、新しいタブで開く、リンクをコピーする操作を選べます。「新しいウィンドウ」はリンク先だけを手前に表示し、元のウィンドウを開いていた全タブごと裏側へ移します。入力を残して並行作業するときは「新しいタブ」を使います。無料は3タブ、Proは5タブまでです。

2. テンプレートを挿入

  1. 「☰ → テンプレートを使う」で一覧を開きます。
  2. 下の「メッセージ」欄をタップし、入力位置を選びます。
  3. フロート一覧から文章を選ぶと入力されます。一覧は開いたままです。
  4. 再度「テンプレート」を押すか「格納」で一覧を閉じます。

文章は「設定 → テンプレート」で編集できます。パスワード・認証コード・決済情報は保存しないでください。

練習用の入力欄

送信機能はありません。入力内容はこのページから保存・送信しません。架空の情報で試してください。

3. 自動入力を試す

設定の「自動入力」で自由入力ルールを作り、ワードを「会社名」、内容を「サンプル会社」にします。このページで「自動入力」を押すと空欄に入力します。入力済みの欄は上書きしません。対象サイトを設定すると、そのサイトだけで使用できます。

4. 検索設定を保存・共有

設定の「サイト・検索設定」でサイトを作成します。自動追加はしません。作成したサイト設定はファイルへ書き出し、GitHubに保存したURLや端末のファイルから読み込めます。

サイト設定共有の手順へ

操作バーと起動ページ

「☰ → ブラウザ上の表示をカスタマイズ」で表示を切り替えます。戻る・検索・再読込は初期状態でON、再読込は検索の行の右端です。起動先は設定から変更できます。この版への更新時は、一度だけ使い方ページへ切り替わります。

プロファイルで使い分ける

設定でGoogle / yobi、Google / workなどのプロファイルを作り、「☰ → プロファイルを開く」で名前を1つ選びます。現在のページで使えるプロファイルが先に表示されます。同じログイン環境の設定を切り替えるときはページと入力を保ち、別のログイン環境やサイトへ切り替えるときは確認後に開き直します。新しく作成したプロファイルは独立したログイン環境を持ち、同じプロファイルのタブ同士はログイン状態を共有します。

旧設定のログイン環境は共有状態で残ることがあります。必要に応じて設定からログインを分離し、サイトでログインし直してください。プロファイル名と色は目印のため、送信や申込みの前にはWebサイト内のログイン中の利用者も確認してください。

プロファイルの作成・移行を確認 →

タブの復元と休止

操作メニューの「保存ページ・履歴」には、お気に入り、最近閉じたタブ、最近開いたページがこの順で表示され、最初は閉じています。最近閉じたタブは無料5件・Pro10件まで保存し、URLと使用プロファイルを復元できます。入力内容、スクロール位置、戻る履歴は復元しません。入力変更を検出すると、プロファイル切替・タブを閉じる・強制再読込の前に確認します。通常のタブ切替ではページと入力を保持します。特殊な入力欄では入力変更を検出できない場合があります。

「使っていないタブを休止」は、入力していない別タブの表示処理を解放します。再び選ぶと最新URLを開き直します。「このページを強制再読込」は、現在のURLとログイン状態を保ちながら表示を作り直します。改善しない場合は操作メニューで画像・通信キャッシュだけを削除できます。Cookieやサイトの保存領域は削除しませんが、サイトの認証期限によって再ログインが必要になることがあります。自動リセットは行いません。

いつものWebを、使いやすく。

このページで検索と入力を練習できます。アプリの登録・ログインは不要です。

1. ページ内を検索

アプリ下部の「位置を検索」を押してみてください。初期設定の検索文字「お問い合わせ」に一致するボタンへ移動します。複数候補は押すたびに順番に移動し、1周を1検索として数えます。0件は数えません。ボタンを勝手に押したり送信したりはしません。

検索文字は「☰ → 設定 → サイト・検索設定」で変更できます。

お問い合わせの練習へ

タブでページを分ける

URL欄の下にある「＋」でタブを追加し、タブ名で切り替え、右端の「×」で閉じます。最後の1枚は閉じられません。このページ内のリンクを長押しすると、別タブで開く操作を試せます。無料は3タブ、Proは5タブまでです。

2. テンプレートを挿入

  1. 「☰ → テンプレートを使う」で一覧を開きます。
  2. 下の「メッセージ」欄をタップし、入力位置を選びます。
  3. フロート一覧から文章を選ぶと入力されます。一覧は開いたままです。
  4. 再度「テンプレート」を押すか「格納」で一覧を閉じます。

文章は「設定 → テンプレート」で編集できます。パスワード・認証コード・決済情報は保存しないでください。

練習用の入力欄

送信機能はありません。入力内容はこのページから保存・送信しません。架空の情報で試してください。

3. 自動入力を試す

設定の「自動入力」で自由入力ルールを作り、ワードを「会社名」、内容を「サンプル会社」にします。このページで「自動入力」を押すと空欄に入力します。入力済みの欄は上書きしません。対象サイトを設定すると、そのサイトだけで使用できます。

4. 検索設定を保存・共有

設定の「サイト・検索設定」でサイトを作成します。自動追加はしません。作成したプロファイルはファイルへ書き出し、GitHubに保存したURLや端末のファイルから読み込めます。

プロファイル共有の手順へ

操作バーと起動ページ

「☰ → ブラウザ上の表示をカスタマイズ」で表示を切り替えます。戻る・検索・再読込は初期状態でON、再読込は検索の行の右端です。起動先は設定から変更できます。この版への更新時は、一度だけ使い方ページへ切り替わります。

サイトの構造によって入力・検索に対応しない場合があります。読み込み中は完了後に検索し、画像による位置ずれを一定時間補正します。手動操作すると補正は止まります。

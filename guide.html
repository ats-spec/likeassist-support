いつものWebを、使いやすく。

このページで検索と入力を練習できます。アプリの登録・ログインは不要です。

1. ページ内を検索

画面下部の「位置を検索」を押してみてください。初期設定では「お問い合わせ」を検索し、その文字を含むボタンやリンクへ移動します。候補が複数あるときは、「位置を検索」を押すたびに次の候補へ移動します。最初の候補へ移動すると1検索として記録され、残りの候補を確認しても追加では数えません。途中でやめた場合も同じです。候補が見つからないときは回数に含みません。LikeAssistがボタンを押したり、フォームを送信したりすることはありません。

検索文字は「☰ → 設定 → サイト・検索設定」で変更できます。

「お問い合わせ」を検索して練習

タブとウィンドウを使い分ける

URL欄の下にある「＋」で現在のウィンドウにタブを追加できます。タブ名を押すと切り替わり、右端の「×」で閉じます。最後の1つのタブは閉じられません。ページ内のリンクを長押しすると、現在のタブ・新しいタブ・新しいウィンドウで開くか、リンクをコピーするかを選べます。新しいウィンドウを開くと、リンク先が手前に表示され、元のウィンドウとそのタブは裏側に移ります。入力中のページを残して作業するときは、新しいタブを使ってください。タブは無料で3個、Proで5個までです。

2. テンプレートを挿入

  1. 「☰ → テンプレートを使う」で一覧を開きます。
  2. 下の「メッセージ」欄をタップし、文字を入れたい位置にカーソルを置きます。
  3. 表示された一覧から文章を選ぶと、その位置に挿入されます。一覧は閉じません。
  4. もう一度「テンプレートを使う」を押すか、「格納」を押して一覧を閉じます。

文章は「設定 → テンプレート」で編集できます。パスワード・認証コード・決済情報はテンプレートに登録しないでください。

練習用の入力欄

送信機能はありません。入力内容はこのページから保存・送信しません。架空の情報で試してください。

3. 自動入力を試す

設定の「自動入力」で自由入力ルールを作り、目印を「会社名」、入力内容を「サンプル会社」にします。このページに戻って「自動入力」を押すと、目印が一致する空欄に入力します。すでに入力されている欄は上書きしません。対象ドメインを設定した場合は、そのドメインのページで使えます。

4. 検索設定を保存・共有

設定の「サイト・検索設定」でサイトを作成します。自動追加はしません。作成したサイト設定はファイルへ書き出し、GitHubに保存したURLや端末のファイルから読み込めます。

サイト設定共有の手順へ

操作バーと起動ページ

「☰ → ブラウザ上の表示をカスタマイズ」で、ブラウザに表示する操作を選べます。戻る・検索・再読込は初期状態でONです。再読込は検索ボタンと同じ行の右端に表示されます。起動時に開くページは「設定 → サイト・検索設定」で、「前回のページ」「指定したURL」「サイト設定の開始URL」から選べます。初期設定は使い方ページのURLを開きます。

ログイン先を分ける

通常は、使いたいサイトのサイト設定を1つ作れば十分です。同じサイトでログイン環境を分けたい場合に限り、同じURLのサイト設定をもう1つ作ります。「私用」「仕事用」などは名前の例です。好きな名前を付けてください。「☰ → プロファイルを開く」で使う設定を選びます。現在のページで利用できる設定が先に表示されます。同じログイン環境の設定に切り替えると、ページと入力を保ちます。別のログイン環境やサイトへ切り替える場合は、確認後にページを開き直します。同じプロファイルのタブ同士はログイン状態を共有します。

旧設定の一部は、ログイン状態を共有する場合があります。必要に応じて設定からログインを分離し、サイトでログインし直してください。プロファイル名と色は見分けるための目印です。送信や申込みの前に、Webサイト上でログイン中の利用者を確認してください。

タブの復元と休止

操作メニューの「保存ページ・履歴」には、お気に入り、最近閉じたタブ、最近開いたページがこの順で並びます。各一覧は最初は閉じています。最近閉じたタブは無料で5件、Proで10件まで保存し、URLと使用プロファイルを復元できます。入力内容、スクロール位置、戻る履歴は復元しません。入力内容の変更を検知したタブでは、プロファイル切替・タブを閉じる・強制再読込の前に確認が表示されます。通常のタブ切替ではページと入力内容を保持しますが、一部の特殊な入力欄では変更を検知できない場合があります。

「使っていないタブを休止」は、入力中ではない別タブのWeb表示をいったん終了します。再び開くと、そのタブのURLを読み込み直します。「このページを強制再読込」は、現在のページを作り直して読み込みます。通常はCookieなどのログイン情報を引き継ぎますが、サイト側の認証期限などにより再ログインが必要な場合があります。改善しない場合は、操作メニューから画像・通信キャッシュを削除できます。この操作ではCookieやサイトの保存データを削除しません。ページやタブを自動でリセットすることはありません。

# LikeAssist 公開サイト

LikeAssist の公式案内、使い方、サポート、プライバシーポリシーを公開するGitHub Pagesリポジトリです。

`site/` を編集用の正本とし、公開時は同じ内容をリポジトリのルートへ反映します。

- `index.html`: メインページ
- `guide.html`: アプリ内から開く使い方・練習ページ
- `profiles.html`: 検索プロファイルの保存・共有・読み込み
- `support.html`: サポートとお問い合わせ
- `privacy.html`: プライバシーポリシー
- `terms.html`: 利用規約

問い合わせ先：`ats.apphelp@gmail.com`

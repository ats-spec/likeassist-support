PROFILE GUIDE

選ぶのは、プロファイルだけ。

通常は、使いたいサイトの設定を1つ作れば十分です。同じサイトでログイン環境を分けたい場合だけ、サイト設定（プロファイル）を追加します。以下はその場合の例です。「私用」「仕事用」など名前は自由で、決まった名前やGoogle専用の設定は必要ありません。

1プロファイル＝1つのログイン環境

例：あるサイトを1つの環境で使う

プロファイル名は自由に設定

この環境用の検索・自動入力設定

このプロファイルのタブ同士はログインを共有

追加する例：同じサイトでログインを分ける

必要な人だけ、もう1つプロファイルを作成

名前は自由。「私用」「仕事用」など

1つ目のプロファイルとはログインを分離

プロファイル名と色は、設定を見分けるための目印です。Webサイト内で別の利用者にログインし直す操作までは制限しません。送信や申込みの前に、サイト上でログイン中の利用者を確認してください。

作成と切替

  1. 1つのログイン環境だけでよい場合は、サイト設定を追加する必要はありません。
  2. 同じサイトでログイン環境を分けたい場合だけ、「☰ → 設定 → サイト・検索」から「サイト設定を追加」を選びます。
  3. 分けたいサイトのURLを登録し、見分けやすい名前を付けます。例と同じ名前にする必要はありません。
  4. 「☰ → プロファイルを開く」で使う設定を選びます。プロファイルを開くときに、別途アカウントを選ぶ画面はありません。
  5. 新しいプロファイルを開いたら、初回はその環境で使うアカウントにWebサイト上でログインします。LikeAssistがログインボタンを押したり、フォームを送信したりすることはありません。

入力途中のページから切り替えるときは確認が表示されます。キャンセルすれば、現在のページに戻ります。

旧設定はどうなる？

以前の複数アカウントは、専用の保存先IDを維持して独立したプロファイルに分けます。タブ・お気に入り・履歴の対応も移します。元の通常ブラウザ用設定は残り、ログインを共有します。

旧設定に保存したID・パスワードは、元のプロファイルに残します。分割先へ自動コピーしません。プロファイル数が上限を超えても削除せず、設定から「利用枠の先頭へ移動」して使用対象を選べます。

既存の共有プロファイルを分離する場合は、設定内の「ログイン・パスワード → ログインを分離して使う」を選びます。通常ブラウザのログインはコピーせず、入力中のタブは閉じます。確認後に実行し、サイトでログインし直してください。

保存したアカウントをログイン欄に入力する

ID・メールアドレス欄またはパスワード欄をタップすると、使用中のプロファイルに保存したアカウントを選べます。手順は「アカウントを選ぶ → Face ID、Touch IDまたは端末パスコードで本人確認 → 空欄に入力」です。入力内容を確認してから、サイトのログインボタンをご自身で押してください。Appleの「パスワード」の候補とは別の機能です。

  1. 操作メニューの「このサイトの保存ID・パスワード」を開き、本人確認します。
  2. 「編集する」から、アカウント名・ID・パスワードを登録し、保存します。
  3. 通常はプロファイルのドメインを入力先に使います。Googleの google.com／www.google.com は accounts.google.com にも対応します。
  4. ほかのログイン先を使う場合だけ、保存情報にそのホスト名を指定します。共通設定では、各保存情報にログイン先を指定してください。
  5. Webページへ戻り、ログイン欄をタップして、使うアカウントを選びます。

以前から登録した情報が候補に表示されない場合は、「このサイトの保存ID・パスワード」を本人確認して一度開いてください。共通設定では、保存情報ごとにログイン先も登録してください。本人確認前に表示されるのは、候補を選ぶためのアカウント名とログイン先です。ID・パスワードは、選択後に本人確認が終わってから入力されます。

入力済みの欄は上書きしません。別アカウントのIDが入っている場合は、IDを消してから選び直してください。IDとパスワードを別ページで入力するサイトでは、それぞれの欄で同じアカウントを選びます。特殊な入力欄や埋め込み画面では使えない場合があるため、その場合はコピー・貼り付けをお試しください。

保存情報の閲覧・編集にも端末認証が必要です。アプリを離れるとロックし、未保存の編集は破棄されます。基本自動入力は共通情報を使うか、プロファイル専用の情報を登録するか選べます。プロファイルの複製や共有には、ログイン情報や専用の自動入力情報は含まれません。

無料とPro

無料は3プロファイル、Proは20プロファイル。同じサイトでログイン環境を2つに分ける場合は、プロファイル枠を2件使います。動作中のタブは無料3つ・Pro5つ。お気に入り・最近閉じたタブから必要なページを開き直せます。復元するのはURLと使用プロファイルで、入力内容は復元しません。
